+ Para garantizar que las «fechas y horas de último acceso» de tus archivos no se vean alteradas por los análisis de NetApp Data Classification, configura el usuario de Active Directory con permisos de Write Attributes en CIFS o permisos de escritura en NFS. Si es posible, configura el usuario de Active Directory como parte de un grupo principal de la organización que tenga permisos para todos los archivos.
