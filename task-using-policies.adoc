= Administre consultas guardadas con NetApp Data Classification
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Data Classification te permite guardar consultas de búsqueda y crear filtros personalizados para encontrar datos en la página de Investigación. Puedes usar consultas predefinidas o crear consultas guardadas y políticas para actuar sobre los datos que coincidan.

La pestaña *Consultas guardadas* en el panel de Cumplimiento enumera todas las consultas guardadas predefinidas y personalizadas disponibles en esta instancia de Clasificación de datos.

Puedes convertir las consultas guardadas en **políticas**. Mientras que las consultas filtran los datos, las políticas te permiten actuar sobre los datos. Con una política, puedes eliminar los datos detectados o enviar actualizaciones por correo electrónico sobre ellos.

Las consultas guardadas también aparecen en la lista de filtros en la página Investigación.

image:screenshot_compliance_highlights_tab.png["Una captura de pantalla de la pestaña Consultas guardadas en el panel de Clasificación de datos."]



[[view-saved-queries-results-in-the-investigation-page]]
== Ver los resultados de las consultas guardadas en la página de Investigación

Para mostrar los resultados de una consulta guardada en la página de Investigación, selecciona el botón image:button-gallery-options.gif["Botón Más"] para una búsqueda y luego selecciona *Investigate Results*.

image:screenshot_compliance_highlights_investigate.png["Una captura de pantalla de la selección de Investigar resultados para una búsqueda específica desde la pestaña Consulta guardada."]



[[create-saved-queries-and-policies]]
== Crear consultas y políticas guardadas

Puedes crear consultas guardadas personalizadas que devuelvan resultados específicos de tu organización. Se muestran resultados para todos los archivos y directorios (recursos compartidos y carpetas) que coincidan con los criterios de búsqueda.

.Pasos
. En la pestaña Investigación, defina una búsqueda seleccionando los filtros que desea utilizar. Verlink:task-investigate-data.html["Filtrado de datos en la página de Investigación"] Para más detalles.
. Una vez que hayas configurado todas las características del filtro, selecciona *Guardar consulta*.
+
image:../media/screenshot_compliance_save_as_highlight.png["Captura de pantalla que muestra cómo guardar una consulta filtrada como una consulta guardada."]

. Nombra la consulta guardada y agrega una descripción.  El nombre debe ser único.
. Opcionalmente, puede guardar la consulta como política:
+
.. Para guardar la consulta como una política, cambie el interruptor *Ejecutar como política*.
.. Elija *Eliminar permanentemente* o *Enviar actualizaciones por correo electrónico*.  Si elige actualizaciones por correo electrónico, puede enviar por correo electrónico los resultados de la consulta a _todos_ los usuarios de la consola con frecuencia diaria, semanal o mensual.  Alternativamente, puede enviar la notificación a una dirección de correo electrónico específica con las mismas frecuencias.


. Seleccione *Guardar*.
+
image:../media/screenshot_compliance_save_highlight2.png["Una captura de pantalla que muestra cómo configurar la consulta guardada y guardarla."]



Una vez que hayas creado la búsqueda o la política, podrás verla en la pestaña **Consultas guardadas**.



[[edit-saved-queries-or-policies]]
== Editar consultas o políticas guardadas

Puede modificar el nombre y la descripción de una consulta guardada.  También puede convertir una consulta en una política y viceversa.

No puedes modificar las consultas guardadas predeterminadas ni los filtros de una consulta guardada existente. En su lugar, consulta los resultados de la investigación de la consulta guardada, cambia los filtros y guarda el resultado como una nueva consulta o política.

.Pasos
. Desde la página Consultas guardadas, seleccione *Editar búsqueda* para la búsqueda que desea cambiar.
+
image:screenshot-edit-search.png["Una captura de pantalla que muestra cómo editar una consulta guardada."]

. Modifica los campos de nombre y descripción.
+
Si lo deseas, puedes convertir la consulta en una política o convertir la política en una consulta guardada. Activa o desactiva la opción *Ejecutar como política* según sea necesario. .. Si vas a convertir la consulta en una política, elige entre *Eliminar definitivamente* o *Enviar actualizaciones por correo electrónico*. Si eliges las actualizaciones por correo electrónico, puedes enviar los resultados de la consulta por correo electrónico a _todos_ los usuarios de la Console diariamente, semanalmente o mensualmente. Como alternativa, puedes enviar la notificación a una dirección de correo electrónico específica con la misma periodicidad.

. Seleccione *Guardar* para completar los cambios.




[[delete-saved-queries]]
== Eliminar consultas guardadas

Puede eliminar cualquier consulta o política guardada personalizada si ya no la necesita.  No puedes eliminar las consultas guardadas predeterminadas.

Para eliminar una consulta guardada, seleccione elimage:button-gallery-options.gif["Botón Más"] Botón para una búsqueda específica, seleccione *Eliminar consulta*, luego seleccione *Eliminar consulta* nuevamente en el cuadro de diálogo de confirmación.



[[default-queries]]
== Consultas predeterminadas

La clasificación de datos proporciona las siguientes consultas de búsqueda definidas por el sistema:

* **Nombres de los interesados - Alto riesgo**
+
Archivos con más de 50 nombres de interesados

* **Direcciones de correo electrónico - Alto riesgo**
+
Archivos con más de 50 direcciones de correo electrónico o columnas de base de datos con más del 50 % de sus filas que contienen direcciones de correo electrónico

* **Datos personales - Alto riesgo**
+
Archivos con más de 20 identificadores de datos personales o columnas de base de datos con más del 50% de sus filas que contienen identificadores de datos personales

* **Datos privados - Obsoletos durante más de 7 años**
+
Archivos que contienen datos personales o información personal sensible, cuya última modificación fue hace más de siete años

* **Protección - Alta**
+
Archivos o columnas de base de datos que contienen una contraseña, información de tarjeta de crédito, número IBAN o número de seguro social

* **Protección - Baja**
+
Archivos a los que no se ha accedido durante más de tres años

* **Protección - Media**
+
Archivos o columnas de bases de datos que contengan identificadores de datos personales, incluidos números de identificación, números de identificación fiscal, números de permiso de conducir, números de identificación médica o números de pasaporte

* **Datos personales sensibles - Alto riesgo**
+
Archivos con más de 20 identificadores de datos personales confidenciales o columnas de base de datos con más del 50 % de sus filas que contienen datos personales confidenciales
