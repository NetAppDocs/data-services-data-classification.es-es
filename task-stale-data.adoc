= Personalice la definición de datos obsoletos en NetApp Data Classification
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Data Classification identifica los datos obsoletos para que puedas detectar oportunidades de ahorro y abordar los riesgos de gobernanza. Personaliza la definición de datos obsoletos para adaptarla a las necesidades de tu organización e identifica los datos obsoletos según cuándo se accedieron o modificaron por última vez.

Los datos obsoletos pueden definirse en función de cuándo se _accedió por última vez_ o se _modificaron por última vez_. Puedes elegir un periodo de entre seis meses y diez años.

De forma predeterminada, los datos se consideran obsoletos si se modificaron por última vez hace tres años.

.Definir datos obsoletos
. En Clasificación de datos, seleccione **Configuración**.
. En la página Configuración, selecciona la pestaña **Settings**.
. Bajo el título Definición de datos obsoletos, selecciona *Editar*.
. En el menú desplegable **Propiedades del archivo**, elige si quieres definir los datos obsoletos según cuándo se *accedió por última vez* o *modificó por última vez*.
. Seleccione el período de tiempo para la definición de datos obsoletos.
. Seleccione **Guardar**.
